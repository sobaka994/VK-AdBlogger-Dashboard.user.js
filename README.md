# Инструкция по установке

## Что нужно сделать

**Шаг 1. Установите Tampermonkey**

Откройте в браузере ссылку и нажмите «Установить»:

- **Chrome / Edge / Яндекс.Браузер:** https://www.tampermonkey.net/
- **Firefox:** https://addons.mozilla.org/ru/firefox/addon/tampermonkey/

**Шаг 2. Установите скрипт**

Перетащите файл `VK-AdBlogger-Dashboard.user.js` в окно браузера. Откроется страница с кнопкой **«Установить»** — нажмите её.

Если перетаскивание не сработало: откройте Tampermonkey → «Панель управления» → вкладка «Утилиты» → «Импорт из файла» → выберите скачанный файл.

**Шаг 3. Откройте кабинет VK AdBlogger**

Зайдите на **https://adblogger.vk.ru/** и войдите в свой аккаунт.

В правом нижнем углу появится синяя кнопка **«📊 VK Аналитика»** — нажмите её.

**Шаг 4. Первый запуск**

- Введите название профиля (например, «Основной кабинет») и подтвердите.
- Нажмите **«Загрузить всё»** — скрипт начнёт собирать данные.
- Дождитесь окончания и пользуйтесь таблицей и аналитикой.

---

## Важно знать

- **Данные хранятся только у вас в браузере.** Никуда не отправляются, на серверы не уходят.
- **Если закроете страницу — ничего не потеряется.** Загрузку можно продолжить с того же места.
- **Не открывайте кабинет с этим скриптом в двух вкладках одновременно** — одна из них покажет «Аналитика открыта в другой вкладке». Это защита от порчи данных.
- **Обновление скрипта:** Tampermonkey сам предложит обновление, когда выйдет новая версия. Просто нажмите «Обновить».

---

## Если что-то не работает

- Нет кнопки «📊 VK Аналитика» → проверьте, что скрипт включён (иконка Tampermonkey → скрипт должен быть с зелёным переключателем).
- Надпись «Нужен актуальный Chrome / Edge» → обновите браузер.
- Кнопка не появилась после установки → перезагрузите страницу `adblogger.vk.ru` (F5).

ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ
VK AdBlogger — Аналитика

1. ОТКРЫТИЕ ПАНЕЛИ

Зайдите на adblogger.vk.ru. В правом нижнем углу нажмите кнопку
"VK Аналитика". Откроется окно с таблицей заявок.


2. ЗАГРУЗКА ДАННЫХ

Первый раз: нажмите "Загрузить всё". Скрипт соберёт список ваших
заявок с сервера. Дождитесь окончания — прогресс виден сверху.

Если остановили или закрыли страницу — нажмите "Продолжить
загрузку", работа пойдёт с того же места.

Кнопка "Уточнить показатели" догружает подробности по заявкам,
у которых не хватает цифр. Запускайте её по необходимости.


3. ТАБЛИЦА ЗАЯВОК

Здесь все ваши заявки со статистикой: клики, заказы, выкуп,
прогноз и факт вознаграждения.

Поиск — по товару, номеру заявки или сообществу.
Фильтр по категории — опубликованные, без публикации, отклонённые.
Сортировка — нажмите на заголовок столбца или выберите в списке.
Клик по заголовку ещё раз меняет направление сортировки.

Кнопка "Excel" выгружает всё в файл.


4. АНАЛИТИКА

Нажмите "Аналитика" в верхней части окна.

Выберите период (сегодня, неделя, месяц, всё время или свой),
группировку (по дням, неделям, месяцам), нужный показатель
и сообщество.

Вы увидите: сводные цифры сверху, график по периодам,
топ сообществ, структуру заказов и таблицу по периодам.

Важно: графики показывают накопленные показатели заявок по дате
их публикации. Это не события, произошедшие за выбранный период.
Свежие публикации имели меньше времени набрать результаты.


5. ПАМЯТЬ И ПРОФИЛИ

Все данные хранятся только в вашем браузере. Никуда не отправляются.

Если ведёте несколько кабинетов — создайте отдельный профиль
для каждого: "Новый профиль". Переключение — в списке "Память".

Кнопка "Очистить профиль" удаляет все сохранённые данные.


6. ОБНОВЛЕНИЕ ДАННЫХ

"Обновить список с начала" — заново собирает список заявок.
"Обновить все карточки" — перезапрашивает подробности по всем
заявкам. Занимает время, используйте когда нужно освежить цифры.
"Повторить ошибки" — повторяет только те заявки, где была ошибка.

Кнопка "Остановить" прерывает любую операцию. Прогресс сохраняется.


7. ЧАСТЫЕ ВОПРОСЫ

Нет кнопки "VK Аналитика"?
Проверьте, что скрипт включён в Tampermonkey (переключатель зелёный)
и перезагрузите страницу.

Появилось "Аналитика открыта в другой вкладке"?
Закройте лишние вкладки с adblogger.vk.ru и перезагрузите эту.

Не хватает цифр в некоторых заявках?
Нажмите "Уточнить показатели" — скрипт догрузит недостающее.

Пустые значения — это не нули. Это значит, что сервер не отдал
число. Скрипт не подставляет нули вместо неизвестных данных.
